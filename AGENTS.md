# Rückmeldungen

Verbesserungsvorschläge und darin enthaltene Namen nicht an eine KI übermitteln oder als Agentenkontext einlesen. Das betrifft GitHub-Issues aus dem Rückmeldeformular und heruntergeladene Textsammlungen.

Die Sammlung läuft ausschließlich zwischen GitHub und dem Browser der herunterladenden Person. Tests ausschließlich mit erfundenen Daten durchführen. Für die Umsetzung späterer Rückmeldungen separat freigegebene Aufgaben verwenden.
